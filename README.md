# GadgetGalaxy – Gadget Store Management System

GadgetGalaxy is a Java-based desktop application developed as an academic project for the Object-Oriented Programming (OOP) module.

The system is designed to support the daily operations of a gadget retail store by providing a structured platform for managing products and sales transactions. It demonstrates the practical application of Object-Oriented Programming concepts, database connectivity, and desktop application development.

## 🎯 Project Objectives

- Develop a desktop-based gadget store management system.
- Apply Object-Oriented Programming principles in a practical application.
- Integrate a relational database for data management.
- Simplify product and sales management operations.
- Build an interactive graphical user interface.

## ✨ Main Functional Areas

- Product Management
- Sales and Transaction Management
- Database Connectivity
- User Interface Management
- Gadget Store Operations

## 🧠 OOP Concepts

This project demonstrates the practical use of fundamental OOP concepts:

- **Encapsulation** – Organizing data and methods within classes.
- **Inheritance** – Reusing functionality through class relationships.
- **Polymorphism** – Supporting different implementations of methods.
- **Abstraction** – Managing complexity through simplified interfaces and structures.

## 🗄️ Database

Microsoft SQL Server is used for relational database management and application data storage through JDBC connectivity.
